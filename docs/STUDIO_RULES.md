## 二、视觉拒稿标准（对照封面）

### 必须像封面

1. **底色**：炭黑层级（约 `#0e0e0e` → `#131313` → `#1c1b1b`），用明暗分层，不靠画框线。
2. **主色**：琥珀 `#ffb866`（主按钮、强调、选中光感）。
3. **辅色**：电蓝 `#8dcdff`（仅数据 / 链接 / 激活指示，少用）。
4. **正文色**：`#e5e2e1`（暖白）。界面装饰文字尽量不用纯白 `#FFFFFF`。
5. **字体**：大标题用 **Noto Serif**；正文 **Inter**；小标签 / 元数据 **Manrope**（全大写或加字距）。
6. **边界**：禁止用 1px 实线框划分区域；必要时只用「幽灵边」——约 0.5px、低透明。
7. **主按钮**：琥珀渐变，不要用系统默认蓝 / 绿当主操作。
8. **浮层**（顶栏、弹窗）：玻璃感 + 大而淡的阴影，不要冷灰「后台管理」脸。

### 一眼否决（出现即打回）

- 确认框 / 提示框变成冷灰底 + 蓝色主按钮  
- 成功态乱用不在色板里的翠绿、信息态乱用默认蓝（应用电蓝或琥珀语义）  
- 导演台时间轴 / 监视器长期用「游戏引擎绿」当品牌色  
- 同一条用户路径上，封面一套皮、工具里另一套皮  

### 可读性例外（允许，但要克制）

- **输入框里用户正在打的字**：可为了看清而更亮（含接近白），与界面装饰字区分。  
- **3D 视口里的辅助线 / 骨骼**：可为操作清晰用高对比色，但工具栏、按钮、面板仍须遵守上面色板。

## 三、浅色主题（导演已确认）

**拍板：L2 浅色琥珀 + 画布暗房（方案 A）**

| 层级 | 策略 |
|------|------|
| **全站浅色（L2）** | 功能壳 / 画廊 / 收藏等：`data-theme=light` 时暖纸底（`#faf6f0` → `#f5ede4`），**主色仍琥珀** `#ffb866`，电蓝 `#8dcdff` 仅辅色；禁止青蓝主色 |
| **无限画布** | **始终暗房** `theme-dark`（`#12100e` 暖炭底），不跟随全站浅色切换；靠琥珀/字体/动效与封面同店 |
| **主页封面** | 当前：`light` 切换下封面仍用暗色电影感 token（历史实现）；**将来亮封面**另开波次，换 `[data-cover-page]` 在 light 下的暖羊皮纸 token |

### 为何画布不跟亮

- 节点、连线、缩略图长时间盯屏，暗底更稳  
- 琥珀运行态 / 电蓝连线已在暗底调好  
- D3 + `instantExit` 过渡针对「亮壳 → 暗画布」，白闪风险更低  

### 将来若要做全站统一浅色画布（方案 B，暂缓）

暖浅 token 参考（勿用冷灰 `#f8fafc`）：

- `--page` `#ece6de`（羊皮纸）
- `--grid` `rgba(183,113,0,.07)`
- `--card` `#fffcf8` → `#f7f2ea`
- `--text` `#2a2520`
- `--strong` `#b77100` / `#ffb866`

需单独波次施工 `infinite-canvas.css` 浅色段。
