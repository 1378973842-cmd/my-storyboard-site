# Mx-Shell 运镜词典（Seedance 视频提示词用）

本文件供 Mx-Shell 生成【画面内容】时强制参考。目标：运镜名词正确、可执行、有戏剧动机；禁止名词堆砌与矛盾组合。

后续有新资料时，只增补本文件，不必改主 skill 结构。

## 运镜四件套（每镜强制）

写运镜时必须同时具备：

1. **手法名**：本词典中的标准名（中文优先）
2. **方向/路径**：向前 / 向左 / 自下而上 / 环绕半圈 / 贴右肩后方跟随 等
3. **速度质感**：缓慢 / 匀速 / 加速 / 骤然 / 先静止后推进
4. **戏剧动机**：逼近压迫 / 揭示空间 / 跟随主体 / 情绪失稳 / 收束离场 等

正确示例：

```text
中景 + 过肩跟拍，机位贴主角右肩后方，随侧移匀速横移，枪口始终压在画面右三分：……
```

错误示例：

```text
中景：角色走动
高级电影感运镜
固定机位推进
手持稳定器跟拍
```

## 分类 A · 运镜（相机如何运动）

| 中文 | 英文参考 | Seedance 写法要点 | 常用动机 |
|---|---|---|---|
| 固定镜头 | Static | 机位不动，只写景别/角度/表演 | 对白、表演、气氛凝视 |
| 摇摄 | Pan | 三脚架水平转动；写清左→右或右→左 | 跟随横移主体、扫视环境 |
| 俯仰拍摄 | Tilt | 垂直转动；写清上摇/下摇 | 展示高度、压迫、发现 |
| 推进 | Dolly In | 机位整体前移靠近；勿与变焦混用 | 亲密、压迫、聚焦 |
| 拉远 | Dolly Out | 机位整体后移远离 | 揭示环境、抽离、收束 |
| 横移 | Truck / Track lateral | 机位左右平移；可写贴侧面跟随 | 并排行走、侧向揭示 |
| 升降 | Pedestal | 机位整体升高/降低（不是俯仰） | 换高度信息、权力变化 |
| 手持 | Handheld | 轻微呼吸感抖动；写「贴身/追逐」 | 紧迫、纪实、慌乱 |
| 稳定器 | Steadicam | 流畅穿行；勿与手持同句 | 长距离穿场、流畅跟随 |
| 摇臂 | Crane / Jib | 大幅度升降+横移；写起止高度感 | 建立镜头、史诗收尾 |
| 变焦 | Zoom | 焦距变，机位可不动；写推近/拉远变焦 | 强调、惊吓、喜剧 |
| 希区柯克变焦 | Dolly Zoom | 必须写「推进同时反向变焦」或相反 | 眩晕、顿悟、恐惧 |
| 跟拍 | Tracking | 与主体保持相对距离跟随 | 行动线、追逐 |
| 甩镜 | Whip Pan | 极速水平摇，带运动模糊 | 硬切转场、节奏冲击 |
| 快速变焦 | Crash Zoom | 骤然变焦；慎用 | 强强调、惊吓 |
| 360环绕 | 360 Orbit | 环绕主体；写半圈/全圈、速度 | 展示、眩晕、仪式感 |
| 环绕半圈 | Arc / Orbit partial | 弧形绕主体 | 起势、展示武器/关系 |
| 滑轨跟 | Slider follow | 短距平滑横移/推进 | 产品感、克制跟随 |

## 分类 B · 角度（相机相对主体）

角度不是运镜，但必须与运镜并列写清。

| 中文 | 要点 | 常用动机 |
|---|---|---|
| 平视 | 与眼睛同高 | 中性、对话 |
| 低角度 / 仰拍 | 从下往上看 | 强势、威胁、崇高 |
| 高角度 / 俯拍 | 从上往下看 | 弱势、审视、信息总览 |
| 斜角 / 荷兰角 | 地平线倾斜；勿滥用 | 失衡、不安、疯狂 |
| 鸟瞰 | 接近正上方 | 布局、命运感 |
| 虫瞰 | 贴地极端仰视 | 巨大尺度 |
| 航拍 | 高空大场面 | 建立地理 |

## 分类 C · 景别与机位关系

| 中文 | 要点 |
|---|---|
| 大特写 | 眼/手/物件细节 |
| 特写 | 头肩、表情 |
| 中近景 / 中景 | 腰上，对白互动 |
| 全景 | 全身+近环境 |
| 远景 / 大远景 | 人与环境关系 / 地貌 |
| 主观镜头 | 角色所见 |
| 过肩 | 从一角色肩后看另一角色；常配合跟拍 |

## 分类 D · 光学/特技（慎用，须写条件）

| 中文 | 正确写法 | 何时用 |
|---|---|---|
| 拉焦 | 焦点从前景 A 落到背景 B（或相反） | 注意力转移；**不是**运镜位移 |
| Snorricam / 身体支架 | 相机绑在演员身上朝脸，背景狂动、脸相对稳定 | 眩晕、吸毒、崩溃主观 |
| 子弹时间 | 瞬间近乎静止 + 视角绕行 | 需慢动作语境，勿日常滥用 |
| 长镜头 | 单镜长时间不切；可叠加一种主运镜 | 一镜到底模式优先 |

## 强度档位（由节点传入）

### restrained（克制）
优先：固定、缓慢推进/拉远、轻横移、平视/微俯仰。  
避免：甩镜、快速变焦、360全圈、希区柯克变焦、子弹时间。

### standard（标准，默认）
允许：跟拍、过肩跟、横移揭示、推进/拉远、手持贴身、稳定器穿行、摇臂收尾。  
慎用炫技项：每条提示词最多 1 次甩镜或快速变焦，且必须有动机。

### flashy（炫技）
允许词典全部手法，但仍须四件套完整；同一分镜仍只允许 **1 个主运镜 + 最多 1 次变奏**。

## 禁止的矛盾组合

同一分镜/同一运镜句内禁止：

- 固定 + 推进/拉远/跟拍/横移/环绕
- 手持 + 稳定器
- 把「变焦」写成「推进」而不说明是焦距变化
- 「希区柯克变焦」却不写推进与变焦反向配合
- 「中景运镜」这类把景别当运镜

## 空词黑名单

禁止单独作为运镜描述：电影感运镜、高级运镜、氛围运镜、张力运镜、酷炫运镜、丝滑动效。

## 多机位规则

- 每个 `分镜N`：**一个主运镜**；切镜靠分镜切换，不靠一镜内五种手法连打。
- `景别+运镜` 字段建议写成：`景别 + 角度 + 主运镜，方向/速度，动机：动作…`
- 一镜到底：可在时间轴上标注运镜变化节点，但同一时段仍保持单一主运镜。
