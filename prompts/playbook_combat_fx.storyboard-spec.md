# 分镜格式与配比（知识层）

## 标准分镜结构

| 分镜 | 时长占比 | 镜头类型 | 叙事功能 |
|---|---|---|---|
| SB-01 建立 | 前 20% | 环境远景→角色特写 | 场景氛围建立 + 角色亮相 |
| SB-02 蓄力 | 20–45% | 中景推近/环绕 | 技能准备，能量凝聚，紧张感积累 |
| SB-03 爆发 | 45–80% | 快速跳切 + 特写 | 技能释放，冲击帧密集，高潮段 |
| SB-04 终结 | 后 20% | 拉远俯拍→定格 | 余波扩散，英雄背影，收束感 |

## 每条分镜必须定义

- 时间范围：[start]s–[end]s
- 镜头运动：static / dolly / crane / orbit / handheld
- 角色动作：动词短语描述的具体姿态/攻击
- 环境反应：什么在破碎/移动/发光
- 特效关键词：3–5 个具体 VFX 描述词

## 多角色镜头视角切换

- 主角视角段：跟拍主角出招，敌人只作为攻击目标出现在边缘。
- 敌人视角段：切到敌人正面，展示防御/反击动作。
- 碰撞视角段：第三人称俯拍，双能量碰撞全景。
- 终结视角段：回到主角背影，敌人倒下或消散。

## 四层提示词配比

1. 风格质量层（10%）：渲染引擎 + 色调 + 质感
2. 运镜系统层（15%）：镜头运动 + 切换节奏 + 视角
3. 核心画面层（60%）：0.5–1 秒粒度时间轴微进式拆解
4. 技术细节层（15%）：粒子 + 材质 + 物理反馈 + 氛围
