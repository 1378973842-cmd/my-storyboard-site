# 库布里克规则卡

Use for institutional dread, ritual, madness, dehumanization, axial symmetry, and cold order.

## Core Logic

Space can overpower people. Geometry turns human behavior into ritual, experiment, or breakdown.

## Rules

### 中轴对称压迫

- Use when: institution, hotel, corridor, military, ritual, authority, madness.
- Design: character centered on vanishing point; architecture dominates.
- Effect: space controls the body.

### 机械推进

- Use when: fate, obsession, ritual movement, unavoidable approach.
- Design: slow centered push or track; keep axis stable.
- Effect: movement feels predetermined.

### 冷静观察疯狂

- Use when: behavior is irrational or violent.
- Design: frame calmly, hold longer than comfort, avoid chaotic coverage.
- Effect: the calm image makes madness more disturbing.

### 人物被空间吞没

- Use when: loss of individuality, system pressure, alienation.
- Design: wide frame, large architecture, small centered figure, repeated patterns.
- Effect: human agency shrinks.

## Avoid

- Do not soften geometry for emotional warmth if dread is the point.
- Do not use symmetry unless power/order/madness is active.
