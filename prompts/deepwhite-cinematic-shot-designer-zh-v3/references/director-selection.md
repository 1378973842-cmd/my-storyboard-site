# 导演规则选择

Choose director rule systems by dramatic function, not by taste.

## Quick Map

| 戏剧问题 | 主规则优先 | 可辅佐 |
|---|---|---|
| 角色第一次看见真相、奇观、恐惧或亲情唤醒 | 斯皮尔伯格 | 希区柯克、维伦纽瓦 |
| 多线并行、倒计时、谜题、系统压迫 | 诺兰 | 芬奇、维伦纽瓦 |
| 谎言、审讯、调查、控制、监控感 | 芬奇 | 希区柯克、诺兰 |
| 观众知道危险而角色不知道 | 希区柯克 | 斯皮尔伯格、芬奇 |
| 群像对峙、行动方向、权力冲突 | 黑泽明 | 诺兰、库布里克 |
| 家庭沉默、代际秩序、关系无法说破 | 小津安二郎 | 王家卫、斯皮尔伯格 |
| 爱而不得、暧昧、错过、记忆碎片 | 王家卫 | 小津、朴赞郁 |
| 欲望、复仇、窥视、精密心理操控 | 朴赞郁 | 芬奇、希区柯克 |
| 制度恐惧、冷峻仪式、疯狂、空间秩序 | 库布里克 | 芬奇、维伦纽瓦 |
| 巨大尺度、沉默、神秘、命运压迫 | 维伦纽瓦 | 诺兰、库布里克 |

## Selection Rules

- Pick one primary system. Secondary systems may modify composition or pacing, but must not fight the primary dramatic logic.
- Avoid "director soup". If more than three directors seem relevant, diagnose the scene again.
- Do not write "像某导演". Write "调用某导演的某条规则 because..."
- If the scene is dialogue-heavy, do not assume it needs static coverage. Use power, concealment, and spatial geometry to choose rules.

## Hybrid Patterns

- Spielberg + Hitchcock: emotional discovery with hidden danger.
- Nolan + Fincher: investigation under time pressure; information architecture with controlled surveillance.
- Ozu + Wong Kar-wai: quiet domestic pain and unsaid longing.
- Park + Fincher: psychological control, seduction, manipulation, forensic attention.
- Kurosawa + Kubrick: group power conflict inside a rigid system.
- Villeneuve + Nolan: personal choice dwarfed by cosmic, historical, or institutional scale.
