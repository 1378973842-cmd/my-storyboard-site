# 故事动画 · 镜头语言

**分镜表「镜头描述」** = 唯一事实源（偏视频可执行）。  
**视频段**沿用表全文（含运镜四件套）。  
**线稿逐格**对同号格做**静帧改编**，禁止另起故事，也禁止照抄机位运动过程。

**禁止荷兰角**（产品硬规则）。其余角度可用。

## 镜头描述句式（分镜表每格强制 · 视频向）

按顺序写满（可用逗号串联，但不得缺项）：

1. **景别**（单元格第一个词）
2. **角度**：平视 / 低角度 / 高角度 / 过肩 / 主观（禁止荷兰角）
3. **构图名词**（每格必选，按剧情挑；可组合）：  
   中心构图、三分法构图、框架构图、对角线构图、引导线构图、对称构图、黄金分割构图、纵深构图、负空间构图、三角构图、S形构图、前景遮挡构图、层次构图、开放式构图、封闭式构图  
   - 名词写清后，站位/遮挡细节仍写在后文（与 DeepWhite「构图列 vs 画面描述」同理）
4. **运镜四件套**：手法名 + 方向/路径 + 速度质感 + 戏剧动机  
   - 无运动时写：`固定镜头，机位不动，突出表演节奏`
5. **主体动作**：起→止，可见肢体路径（迪士尼夸张幅度）
6. **表情/口型**：眉眼口具体变化；有台词时写 `角色（语气）："…"` 与口型
7. **空间层次**：前景 / 中景 / 背景 或 左右占位、画面占比
8. **光影**：光源方位 + 明暗 + 色温（禁空词「电影感光影」）
9. **道具状态**（若本格有道具）

正确：`近景，平视，三分法构图，固定镜头，机位不动……角色偏右三分，左侧留门口负空间……`  
错误：只写「好看构图」或全程所有格子都用同一个「中心构图」而无剧情理由

## 可用运镜手法名（分镜表 / 视频段须出现其一）

固定镜头、摇摄、俯仰、推进、拉远、横移、升降、手持、跟拍、过肩跟拍、滑轨跟、变焦、快速变焦、环绕半圈

正确：`近景，平视，推进，机位沿吧台向前匀速靠近角色面部，动机是逼近情绪高潮，……`  
错误：`运镜自然流畅` / `高级电影感运镜` / `镜头缓慢移动`（无手法名）

## 静帧改编规则（线稿逐格专用）

从同号「镜头描述」提炼静帧，**事实对齐、介质不同**：

| 维度 | 线稿（静帧） | 视频（沿用表） |
|---|---|---|
| 景别/角度 | 保留 | 保留 |
| 构图名词 | 保留（三分法构图/框架构图等） | 保留 |
| 装置细节 | 保留（框中框、过肩、插入特写等） | 保留 |
| 姿态/表情/道具 | 写成**定格**瞬间 | 可写起→止过程 |
| 运镜四件套 | **去掉**速度/路径/动机；最多「构图呈推进感的近景定格」 | **完整保留** |
| 格上标注 | **仅镜号**；禁止运镜图表/箭头/运镜词角标 | 文本指挥运镜 |
| 口型 | 可写「口微张」；禁「口型对齐」时间感 | 可写口型与台词节拍 |

正例（线稿）：`近景，平视；角色扬眉张臂定格，构图呈推进感的近景定格；中轴偏右，后景彩旗`  
反例（线稿禁）：`推进，机位自右向左快速滑移，动机是焦虑；口型对齐说出…`  
反例（线稿禁）：`快速变焦逼近面部` / `匀速前移靠近`  
反例（线稿禁）：提示词写「每格标注运镜图表」或图上画推进箭头/运镜图标（标注会漂移且视频不读它）

## 空词黑名单（镜头描述与视频段均禁止）

电影感、高级感、氛围感、张力强、运镜自然流畅、高级电影感运镜、唯美光影（须改写为具体光源）

## 视觉装置（填表时选用，动画喜剧友好）

前景遮挡、框中框、负空间、插入特写（道具/手部线索）、延迟反应、侧面揭示、过肩对视、纵深层次  
全片至少约 40% 的格子使用其中之一（写入镜头描述可见元素，勿只写装置名）。

**前景遮挡构图（电影/摄影义）**：在镜头与主体之间放入前景层，用纵深、虚实、压边或窥视感做出「摄影机所在位置」，打破 AI 画面过干净，**不是**要求「挡住角色身体某部位」当目的。

写「前景遮挡 / 前景遮挡构图」时必须点名：**前景是什么**（物/局部），以及它如何构成层次（虚化前景 / 压画面边缘 / 隔着窥视 / 框住中景主体）。

| 正例（可通过） | 反例（会校验失败） |
|---|---|
| `前景遮挡构图；虚化前景芭蕉叶压在画面左缘，中景女孩站在林间` | `前景遮挡构图`（只剩名词） |
| `前景遮挡构图；隔着虚化门框窥视吧台，中景角色冲咖啡` | `前景遮挡构图；增加电影感/窥视感`（未写前景物） |
| `前景遮挡构图；过肩，前景右肩虚化形成窥视层，中景客人接杯` | `前景遮挡构图；挡住下半脸`（把技巧误解成遮脸目的） |
| `前景遮挡构图；前景桌沿与杯壁贴近镜头形成纵深，主体在中景` | `前景遮挡构图+层次构图`（仍未写前景物） |

常用前景物：门框、窗框、树叶/枝条、栏杆、桌沿、杯沿、蒸汽雾气、肩/过肩、窗帘、车窗、书架边缘。可略虚化，勿喧宾夺主。
