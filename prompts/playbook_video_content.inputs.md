# 剧情动画 · 参数与时长（知识层）

## 输入参数

| 参数 | 必填 | 缺省行为 |
|---|---|---|
| 剧情素材 | 是 | 没有就追问，不要自己编 |
| 总时长 | 否 | 用户没说 → 按素材密度估一个，并在停点里报出你估的数，让用户改 |
| 模式 | 否 | 见步骤 1 |
| 角色参考图 | 否 | 传了图像部件 → 不超过 20 字概括并标注参考图；只有地址、没有图像部件 → 按故事写全。无参考图 → 写详细物理描述 |
| 场景 / 道具参考图 | 否 | 同上 |
| 台词 / 配音 | — | 画布不支持，见原则 7。用户给了台词 → 转成字幕或画面叙事，不要提议配音 |
| 氛围、画风、机位、模型 | 否 | 不追问，用默认；用户提了才采纳 |
| 运镜强度 | 否 | 见步骤 1 |

参考图和文字是分工的，不是重复的：传了图像部件时，文字只写差异，不重述图里已有的。只有地址、没有图像部件时这条不适用，按故事写全。
## 时长规则

这一节只在画布上成立，因为「时长会被供应商改」这件事只在提交时发生。

| 模型 | 单段上限 | 下限 |
|---|---|---|
| seedance-2.0 | 15 秒 | 4 秒 |
| hailuo-h3（默认） | 15 秒 | 5 秒 |

video 不填 model 时按海螺 H3 送出。段数等于总长除以上限向上取整。

规则，按顺序：

1. 用户提的总时长不超过单段上限 → 一次生成，一个节点
2. 用户提的总时长超过单段上限 → 分段，每段不超过上限
3. 用户提的单段时长超过上限 → 先在上下文的 availableModels 里找支持该时长的模型换掉；换不了才告诉用户会被压
4. 段时长被压时，节点上会留下 agentParamClamped 记录。读到它之后必须告诉用户实际时长变了，不要自己吞掉
