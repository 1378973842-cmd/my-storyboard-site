# 特效打斗

> 角色战斗场景的特效视频：分镜 → 四层提示词 → 画布节点。
> 先做资产与风格分析，问清机位和强度，再写分镜；建/连/改自动落板，生成必须走审批卡。
> 正文来自「角色战斗场景特效视频生成」，与画布节点参数或审批规则冲突时，以画布规则为准。

## 在画布上落地时的硬规则

- **分镜剧本写进 prompt 节点**（参数用 `text`），正文里**不要写 `{{节点}}` 引用**；引用只写在 generator / image / video 节点的 `prompt` 里。带引用的文本节点会被直接拒绝。
- 生成节点的 prompt 里必须点名参考节点（`{{img_xxx}}`），并说明它在画面里起什么作用。
- 建节点、连线、改参数会**自动落板**；只有运行生成会出审批卡，卡上点「批准」才跑。
- 一次只推进一个阶段：分析/提问 → 分镜剧本 → 关键帧 → 视频。用户确认当前阶段后再进下一步，不要一次把后面几步都做完。
- 完成一步后用一两句话说明**这一步做了什么、下一步准备做什么**，不要只丢一个提案。

# 角色战斗场景特效视频生成

## 核心方法论

### 1. 叙事驱动的分镜架构

分镜是**单个视频内的时间叙事结构**，不是多个独立视频文件的集合。每个分镜是服务于整体故事弧的时间段：

- **SB-01 建立镜头**：0-25% 时长 → 场景/氛围建立
- **SB-02 冲突蓄力**：25-50% 时长 → 角色亮相，能量积累
- **SB-03 高潮交锋**：50-75% 时长 → 核心战斗序列，特效密集
- **SB-04 终结画面**：75-100% 时长 → 终极招式，环境破坏，英雄定格

每个分镜必须：

1. **推进叙事动能**（不得静态重复）
2. **递进视觉强度**（特效复杂度逐镜提升）
3. **保持空间/角色连续性**（镜头角度与位置符合电影逻辑）

---

### 2. 元素色彩语义体系

技能特效必须绑定明确的色彩-属性映射，不同元素类型遵循固定的视觉语言：

| 元素属性 | 核心色彩 | 情绪关键词 | 粒子形态 |
|---|---|---|---|
| 火系 | 烈红/橙金/炽白 | 热烈、爆裂、威猛 | 火焰团、爆炸光晕、热浪扭曲 |
| 冰系 | 冰蓝/青白/霜白 | 冷冽、凝结、锐利 | 冰晶折射、霜花扩散、寒雾弥漫 |
| 雷系 | 黑紫/深蓝/白电 | 迅猛、暴烈、撕裂 | 树根状电弧、静电粒子、电光闪链 |
| 暗影系 | 紫黑/暗红/血色 | 诡异、吞噬、压迫 | 黑雾翻涌、血色烟尘、暗影触须 |
| 神圣系 | 金白/淡青/圣光 | 耀眼、神圣、净化 | 光羽飘散、圣光柱、体积光扩散 |
| 自然系 | 翠绿/木棕/金黄 | 生机、蔓延、缠绕 | 藤蔓缠绕、叶片旋舞、花粉光点 |

**应用规则**：

- 技能色彩必须与角色服装/武器形成**高对比**或**高融合**二选一
- 同一技能最多使用 2 种主色调，避免色彩混乱
- 场景环境色调应反衬技能色彩（冰系技能搭配暗调场景，火系技能搭配冷灰场景）
- 色彩一旦确定全程保持一致，不得中途变更

---

### 3. 角色战斗类型分析

收到角色输入后，执行**战斗角色分类**：

- **敏捷型**：链式武器、杂技动作 → 重点：运动轨迹、残影、速度线
- **力量型**：重甲、震地打击 → 重点：冲击坑、冲击波涟漪、碎石飞溅
- **法术型**：能量构造、召唤仪式 → 重点：粒子密度、发光强度、体积光

**跨类型交互规则**：

- 敏捷 vs 力量 → 速度线与冲击波碰撞
- 法术 vs 敏捷 → 法术弹幕 vs 闪避残影
- 力量 vs 法术 → 物理打击击碎能量屏障

---

### 4. 四层提示词构建体系

每个战斗视频提示词必须包含四个层级，缺一不可：

**① 风格质量声明层**（10-15% 篇幅）
定义渲染标准、整体风格、色调情绪基调。
3D国漫玄幻风格 + 虚幻引擎5极致画质 + [色调:暗黑/明亮/冷峻] + 电影级[质感词:写实/史诗/梦幻]
必含：渲染引擎名、色调定性词、质感定性词、对比度描述
示例："次世代国漫3D，虚幻引擎5渲染，暗黑史诗风，冷调高级质感，全局光照+动态模糊+景深，60fps流畅度"

**② 运镜系统层**（15-20% 篇幅）
定义镜头运动逻辑、切换节奏、视角变化规律。
分镜节奏公式：[蓄力段(稳定慢推)] → [爆发段(快速切换)] → [余韵段(缓慢拉远)]
运镜语法：推(push in)/拉(pull out)/跟(follow)/环绕(orbit)/仰拍(low angle)/俯拍(high angle)
切换强度：缓慢融合(淡入淡出) vs 快速跳切(硬切) vs 爆点闪白切换
示例："开场极近特写慢推至全身，蓄力段低角度跟拍，爆发瞬间快速跳切至正面碰撞近景，终结段俯拍缓慢拉远定格"

**③ 核心画面层**（50-60% 篇幅，最关键）
采用**微进式时序叙事**——将动作拆解为 0.5-1 秒粒度的连续画面描述。

核心原则：

- **动词密度法则**：每个动作必须用强动词（轰然/迸发/炸裂/席卷/冲破），拒绝弱动词（出现/显示/发生）
- **感官叠加法则**：视觉+听觉+动势同时描述（"震耳咆哮+冲击波轰然炸裂+地面龟裂扩散"）
- **尺度对比法则**：通过大小对比制造压迫感（"渺小人影 vs 巨型能量球"）
- **VFX绑定法则**：特效必须附着于动作（"獠牙**迸发**紫色火焰" 而非 "紫色火焰出现"）

时序拆解模板：
[Initial state] → [Trigger action] → [Environmental response] → [Effect cascade] → [Climax beat] → [Resolution pose]

示例（0.5秒粒度）：
0.0-0.5s: 角色摆出施法姿势，双手结印
0.5-1.0s: 掌心开始发光，眼瞳迸射元素光芒
1.0-2.0s: 地面符文阵列依次激活（螺旋扩散）
2.0-3.0s: 能量柱从符文中心轰然升起
3.0-4.0s: 技能形态在能量柱内凝聚成形
4.0-5.0s: 技能爆发冲出，能量柱炸裂成粒子

**④ 技术细节强化层**（10-15% 篇幅）
用材质、粒子、物理反馈细节拉满真实感。
粒子细节：冰晶折射光线/火花四溅轨迹/烟尘翻涌体积感/静电游丝缠绕
材质细节：冰面反光镜面质感/金属划痕锈迹/布料褶皱飘动/皮肤毛孔纹理
物理反馈：地面龟裂/碎石飞溅/热浪扭曲空气/冲击波涟漪扩散
氛围压迫感：空气凝结感/尘埃悬浮体积光/低频震动嗡鸣感

### 5. 专业动画冲击帧技法（可视化描述体系）

传统数值型指令（如"亮度246/255"）AI 模型无法精确执行，必须转换为**画面内发生的可视化动作描述**。

**闪白帧（白屏爆闪）—— 场景爆点转场**
用途：能量爆发瞬间 / 冲锋转交锋 / 终极大招释放
基础版："画面爆闪至纯白，如雷击般刺目，瞬间切回战斗场景"
强化版："全屏白色强光瞬间吞没画面，冲击波从中心向外高速环状扩散，带起漫天飞尘与碎石，强光消退后场景骤然切入"
震屏版："爆炸瞬间画面爆白，摄像机剧烈震动，震幅先大后小，持续0.3秒后缓慢恢复稳定"

**黑白帧（去色帧）—— 蓄力与余韵**
用途：技能蓄力压迫感 / 斩杀定格余韵 / 暴风雨前的宁静
去色蓄力："画面色彩骤然褪尽如墨染，仅剩明暗轮廓，元素电弧在黑白画面中格外锐利"
斩杀定格："斩击瞬间画面凝固为黑白慢镜，碎石与尘埃悬浮空中如时间静止，仅角色眼瞳残留一点幽光"
蓄力渐变："画面色彩如潮水般缓缓退去，世界逐渐褪色为冷灰黑白，暴风雨前的死寂压迫感弥漫"

**冲击帧（画面剧变帧）—— 撞击与能量爆发**
用途：拳拳到肉的碰撞 / 能量球爆炸 / 武器交锋
单次撞击："两力相撞瞬间爆出耀眼白光，冲击波环状向外炸裂扩散，地面龟裂，飞尘横飞"
能量二次爆发："能量在碰撞点积压到极限，轰然二次爆发，画面边缘出现强烈镜头畸变，火花如雨四溅"
高频连打："每一击落下画面猛烈一震，闪光与爆裂声此起彼伏，节奏如战鼓密集擂响"

**震屏效果分级**
轻震：摄像机轻微颤抖，如远处爆炸的余震，持续0.2秒后自然恢复
中震：爆炸瞬间摄像机猛烈震动，震幅先大后小，持续0.3秒后缓慢稳定
重震：冲击波正面命中，摄像机剧烈抖动如地震，画面边缘出现运动模糊，0.5秒内逐步恢复
极震：终极大招爆发，摄像机震动到极限，画面短暂失焦+边缘畸变，震动持续0.8秒后如余震般缓缓平息

**完整冲击节奏模板（可直接复用）**
蓄力段：画面色彩如潮水缓缓退去，褪为冷灰黑白，世界陷入死寂压迫；
爆发点：全屏白色强光瞬间吞没画面，冲击波从中心向外高速环状扩散，带起漫天飞尘与碎石，摄像机剧烈震动先大后小持续0.3秒；
冲击连打：每一击落下画面猛烈一震，爆出耀眼白光与冲击波涟漪，能量在碰撞点二次爆发，镜头畸变+火花四溅，节奏如战鼓密集；
余韵定格：斩击后画面凝固为黑白慢镜，碎石悬浮如时间静止，色彩如潮水缓缓回涌，残留粒子在体积光中飘散消逝。

## 工作流程

### 第一步：准备阶段（全部完成才可进入第二步）

**需求挖掘前置交互机制（强制，准备阶段第一步）：**

用户激活 Skill 后，第一件事不是直接收集参数，而是先通过专业提问挖掘用户的真实创作意图。用户往往无法准确描述特效风格，需要 Agent 用专业知识引导用户表达。

触发条件：

- 用户描述模糊（如"两个女的打斗，很华丽"）
- 用户只说了角色/场景，没有说特效风格
- 用户没有明确的技能/招式概念
- 用户表达中缺少风格、元素、节奏等关键信息

禁止行为：

- 收到模糊需求后直接套用默认模板生成 ❌
- 不经引导直接进入参数收集清单 ❌
- 用千篇一律的"玄幻3D史诗风"填充所有需求 ❌

正确执行流程：

STEP 1 — 风格定向提问（单次 ask_human，多个维度）

根据用户需求，从以下维度中选择 3-4 个最相关的提问：

【画风维度】
- 偏写实（真人质感/超写实建模）还是偏二次元（国漫/日漫/3D卡通）？
- 色调偏暗黑压抑还是明亮华丽？

【特效风格维度】
- 有没有喜欢的游戏/动漫技能参考？
  （如：鬼灭之刃的呼吸技、火影的查克拉术、原神的元素爆发、
  崩坏的终结技、王者荣耀的大招特效等）
- 偏向哪种元素属性？
  （火/冰/雷/暗影/神圣/自然/阴阳/机械/血系等）
- 特效风格偏「写意飘逸」（如仙侠飘带剑气）还是「硬核爆炸」
  （如冲击波震地炸裂）？

【动作风格维度】
- 偏向哪种战斗节奏？
  （快速凌厉连击 / 蓄力一击必杀 / 优雅流动舞步式 / 野蛮压制）
- 角色战斗风格偏哪种？
  （剑客/刺客/法师/武者/召唤师/枪手）

【叙事节奏维度】
- 想要有完整故事感（建立→蓄力→爆发→收束）
  还是直接上高潮特效展示？
- 有没有想复刻的具体场景或镜头感觉？
  （如某部电影/动漫的某一幕）

STEP 2 — 整合用户回答，生成个性化创作方案

根据用户的回答，Agent 需要：

1. 用专业语言将用户描述转化为具体的视觉方案
2. 主动提出 1-2 个创意建议（基于用户偏好延伸）
3. 向用户说明将要呈现的效果，例如：

示例回复：
"根据您的偏好，我为您设计了以下方案：

- 风格：国漫3D写实，暗金色调
- 技能特效：参考原神雷元素爆发风格，紫金雷电+冲击波涟漪
- 战斗节奏：快速凌厉连击，每击带残影，终结一击蓄力爆发
- 叙事结构：建立对峙→连击缠斗→终结大招→英雄定格
  您觉得这个方向如何？有需要调整的地方吗？"

STEP 3 — 用户确认创作方向后，进入准备阶段参数收集

用户对创作方向满意后，才进入6项参数收集清单。

注意事项：

- 每次提问聚焦 3-4 个维度，不要一次抛出所有问题
- 用具体的参考案例引导（游戏技能名/动漫招式名），而非抽象的"您想要什么风格"
- Agent 要主动给出选项和建议，降低用户的表达门槛
- 根据用户每一条回答实时调整后续提问方向，而非机械走完所有问题
- 最终生成的脚本必须体现用户的个性化偏好，禁止套用通用模板

🔴 **阶段推进门控（强制阻塞规则）**

以下项目必须**全部经用户明确回答**后，才能进入第二步分镜设计：

| # | 检查项 | 说明 |
|---|---|---|
| 1 | 角色资产 | 参考图已上传 OR AI生成三视图已经用户确认 |
| 2 | 画面比例 | 1:1 / 16:9 / 9:16 |
| 3 | 画面分辨率 | 480p / 720p / 1080p |
| 4 | 场景偏好 | 用户指定描述 OR 交由AI设计 |
| 5 | 视频时长 | 10s / 15s / 20s / 30s / 60s |
| 6 | 特效强度 | 轻微 / 中等 / 极致 |

**禁止行为**：

- 分辨率确认后直接进入生成 ❌
- 将需求描述中的隐含信息视为已确认 ❌
- 任何未被用户明确回答的项，禁止推断替代，必须通过 ask_human 补全 ❌

 **角色资产处理规则（强制）**

IF 用户提供了角色参考图：
→ 直接使用参考图作为角色锚点，进行角色分析，继续收集其余4项

IF 用户没有参考图（包括"没有参考图"/"由AI自由设计"等回答）：
→ 不得跳过角色资产环节
→ 必须先通过 generate_image 生成角色三视图（正面/侧面/背面）
→ 将三视图展示给用户，通过 ask_human 确认外观是否满意
→ 用户明确确认后，以确认图作为角色锚点
→ 禁止仅凭文字描述直接进入视频生成

角色分析维度（收到/确认角色图后执行）

- 服装配色与材质（布料/金属/皮革）
- 武器类型与持握方式（剑/枪/链/拳套）
- 气质定位（冷峻/妖娆/威猛/神秘）
- 战斗风格归类（敏捷型 / 力量型 / 法术型）
- 视觉标志性元素（如"红色铁链" / "黄色重甲"）

场景设计决策树

IF 用户提供场景描述：
→ 提取：地点类型、时间、天气、环境光
→ 识别：可互动元素（可破坏道具、动态环境）

IF 用户委托AI设计：
→ 根据角色冲突类型选择：
  法术决斗 → 古代遗迹、月夜、能量裂缝
  武术对战 → 庭院、雨夜、石柱
  怪物战斗 → 荒原、暴风雨、崩塌结构
→ 设计原则：环境必须参与动作（不只是背景）

技能设计清单

- [ ] 元素属性确定（从色彩语义体系中选择）
- [ ] 技能名称与核心动作（如"天罡烈虎拳"=一拳冲击）
- [ ] 特效优先级排序（如火系=冲击波>火焰团>热浪扭曲）
- [ ] 环境反馈设计（地面龟裂/冰封扩散/风刃切痕）

- **角色参考图质量评估规则（强制）：**

  无论用户提供参考图还是 AI 生成三视图，都必须执行以下质量评估：

  评估维度：

  - [ ] 图片清晰度：是否存在模糊、压缩失真、截图噪点
  - [ ] 细节完整度：服装纹理、武器细节、面部特征是否清晰可辨
  - [ ] 视角完整度：是否包含正面/侧面/背面三个视角
  - [ ] 尺寸充足度：人物是否足够大，细节是否可见

  IF 参考图质量不足（模糊/截图/细节缺失/视角不全）：
  → 不得直接使用低质量图作为唯一锚点
  → 必须以用户提供的图为参考，通过 generate_image 重新生成
    一张高质量、多视角、细节完整的角色三视图
  → 将新生成的完善版三视图展示给用户确认
  → 用户确认后，以完善版三视图作为正式角色锚点
  → 后续所有视频生成，必须引用完善版三视图节点作为 reference_nodes
  → 禁止使用原始低质量图直接生成视频

  IF 参考图质量良好（清晰/细节丰富/多视角）：
  → 直接使用作为角色锚点，无需额外生成
  → 后续所有视频生成，引用此图作为 reference_nodes

  **锚点版本管理规则：**

  - 始终以「最完善版本」的多视图作为后续所有视频的参考锚点
  - 如果中途生成了更完善的版本，所有后续视频节点必须切换引用新版本
  - 在分镜表和锚点清单中明确标注当前使用的角色锚点 node_key

### 第二步：分镜设计阶段

**核心原则**：分镜是同一视频内的时间段划分，不是多个独立视频拼接。一次生成调用产出包含完整分镜序列的单个视频。

**标准分镜结构**：

| 分镜 | 时长占比 | 镜头类型 | 叙事功能 |
|---|---|---|---|
| SB-01 建立 | 前20% | 环境远景→角色特写 | 场景氛围建立+角色亮相 |
| SB-02 蓄力 | 20-45% | 中景推近/环绕 | 技能准备，能量凝聚，紧张感积累 |
| SB-03 爆发 | 45-80% | 快速跳切+特写 | 技能释放，冲击帧密集，高潮段 |
| SB-04 终结 | 后20% | 拉远俯拍→定格 | 余波扩散，英雄背影，收束感 |

**每个分镜必须定义**：

- 时间范围：[start]s - [end]s
- 镜头运动：static / dolly / crane / orbit / handheld
- 角色动作：用动词短语描述的具体姿势/攻击
- 环境反应：什么在破碎/移动/发光？
- 特效关键词：3-5个具体VFX描述词

**进阶技巧**：

- 多角色对战场景需插入敌人镜头（建立→对峙→交锋→斩杀）
- 每个分镜必须包含明确的"动作完成点"

**多角色镜头视角切换逻辑**：
主角视角段：跟拍主角出招，敌人仅作为攻击目标出现在画面边缘
敌人视角段：切换至敌人正面，展示其防御/反击动作
碰撞视角段：第三视角俯拍，展示双方能量碰撞全景
终结视角段：回归主角背影，敌人倒下或消散

**分镜脚本用户确认机制（强制）：**

分镜规划完成后，必须将完整分镜方案展示给用户，通过 ask_human 进行确认：

展示内容包括：

- 每个分镜的时间范围、镜头类型、动作内容、特效关键词
- 角色色彩体系与元素属性说明
- 场景设计方案

确认交互规则：
IF 用户满意：
→ 进入第三步提示词撰写阶段

IF 用户不满意 / 提出修改意见：
→ Agent 根据用户意见修改对应分镜内容
→ 重新展示修改后的分镜方案
→ 再次通过 ask_human 确认
→ 循环执行，直到用户明确表示满意为止
→ 禁止在用户未确认的情况下进入提示词撰写阶段

用户可在此阶段提出的修改方向包括：

- 调整某个分镜的动作设计
- 增减特效类型或强度
- 修改场景细节
- 调整叙事节奏（加快/放慢某段）
- 替换角色动作风格

### 第三步：提示词撰写阶段

按四层体系构建，篇幅分配严格遵守：

1. **风格质量层**（10%）：渲染引擎 + 色调 + 质感
2. **运镜系统层**（15%）：镜头运动 + 切换节奏 + 视角
3. **核心画面层**（60%）：0.5-1秒粒度时间轴微进式拆解
4. **技术细节层**（15%）：粒子 + 材质 + 物理反馈 + 氛围

**冲击帧植入时机（必选项）**：

- 蓄力段必含黑白渐变
- 技能爆发瞬间必含1次闪白帧
- 交锋段每次撞击必含冲击帧描述
- 终结段必含黑白定格+色彩回涌

**提示词长度**：控制在 800-1500 字

### 第四步：生成与验收阶段

**生成规则**：

- 使用 **Seedance 2.0** 模型
- 一次调用产出完整视频，包含所有分镜时序
- 禁止拆分为多个节点后拼接

**质量验收检查项**：

- [ ] 技能色彩是否符合元素语义体系
- [ ] 角色服装/武器是否与确认的参考图一致
- [ ] 是否至少包含1次闪白帧爆点
- [ ] 是否包含1次黑白帧序列
- [ ] 镜头运动是否流畅（无突兀跳跃）
- [ ] 特效密度是否达标（粒子/冲击波/环境破坏）

**不满意时的迭代策略**：

- 技能不够炫 → 增加冲击帧描述密度，强化震屏效果
- 节奏拖沓 → 压缩蓄力段时长，增加爆发段跳切频率
- 画面暗淡 → 风格层添加"高对比度光影"，技能层强化发光粒子
- 角色变形 → 核心画面层增加外观锁定描述（"银发/红衣/铁链武器始终保持"）

## 高级技巧

### 环境互动强化

高质量战斗视频的特效不应「悬浮」于场景之上，而应与环境产生真实物理互动：

- 火焰技能：点燃地面枯草，引燃木质残骸，空气热浪扭曲
- 冰霜技能：地面结冰扩散，石柱冰封炸裂，空气凝结白雾
- 雷电技能：击穿地面留下焦黑痕迹，金属武器反向放电
- 冲击波：掀起地面尘土，吹飞碎石，震碎残破墙体

### 象征性道具设计

每个场景道具应具备**双重功能**：空间元素 + 象征意义：

- 古老石门 → 代表界域屏障（开启=释放力量）
- 崩塌石柱 → 可视化战斗强度（破坏程度=力量量级）
- 天气变化 → 反映角色情绪状态（平静→暴风=怒气积累）

### 慢镜头黄金时机

以下3个时机插入0.5倍速慢镜头可显著提升视觉冲击力：

1. 技能爆发瞬间（能量球离手的0.3秒）
2. 武器交锋瞬间（刀剑相撞火花迸发的0.2秒）
3. 斩杀定格瞬间（敌人倒下前的最后一帧，拉长至0.5秒）

慢镜头描述模板：
"[关键动作]瞬间时间流速骤降，画面进入0.5倍速慢镜头，[细节放大描述]，慢镜结束后时间流速恢复正常"

### 终结定格英雄构图

视频最后1-2秒必须交付**英雄构图**：

- 角色处于主导位置（高处、居中、逆光）
- 环境破坏作为构图框架（烟雾散开、碎石沉落）
- 胜利图腾（武器高举、能量消散、余波扩散）
- 这一帧必须是截图级画面
