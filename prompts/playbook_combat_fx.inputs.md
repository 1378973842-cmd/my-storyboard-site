# 输入参数表（知识层）

## 六项参数可选值

| # | 参数 | 可选值 |
|---|---|---|
| 1 | 角色资产 | 画布已有参考 / 新生成三视图 |
| 2 | 画面比例 | 1:1 / 16:9 / 9:16 |
| 3 | 画面分辨率 | 480p / 720p / 1080p |
| 4 | 场景偏好 | 用户指定 / AI 设计 |
| 5 | 视频时长 | 10s / 15s / 20s / 30s / 60s |
| 6 | 特效强度 | 轻微 / 中等 / 极致 |

## 提问措辞

- 用具体作品/招式做参照，降低表达门槛。
- 每张卡都要有推荐项和一句理由。
- 用户回答后按回答调整下一问，不机械走完清单。
